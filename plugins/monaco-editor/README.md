# Редактор Monaco и Markdown

Встроенный плагин открывает текстовые файлы в [Monaco](https://microsoft.github.io/monaco-editor/). Он применяется к ссылкам в чате, поиску файлов в правой панели и `bb thread open`.

## Работа с файлами

- **Редактирование и сохранение:** `Ctrl+S` на Windows. Если файл изменился на диске после открытия, сохранение останавливается и предлагает Reload или Overwrite. Сначала проверьте внешние изменения, например правки агента.
- **Поиск:** `Ctrl+F`. Доступны несколько курсоров, блочное выделение, парные скобки и сворачивание кода.
- **Подсветка:** около 86 распространённых типов файлов.
- **Markdown:** `.md` и `.markdown` по умолчанию открываются как предпросмотр. Кнопки Preview и Source переключают отображение. Предпросмотр отражает текущий текст редактора, в том числе несохранённые правки; переключение само ничего не сохраняет и не перезагружает. `.mdx` остаётся в текстовом редакторе.
- **Дерево файлов:** кнопка в панели файла открывает навигацию, поиск по пути и раскрытие каталогов. Контекстное меню копирует полный или относительный путь либо имя файла.
- **Палитра команд:** `Ctrl+Shift+P`. По словам `fold`, `sort` и `copy` доступны сворачивание уровней 1–5, рекурсивное сворачивание/разворачивание, сортировка выделенных строк и копирование пути. Сортировка появляется при выделении нескольких строк; команды относятся к последней активной вкладке Monaco.
- **Оформление:** редактор следует теме bb, включая светлые, тёмные и пользовательские палитры.

На macOS вместо Ctrl для основных сочетаний используется Command.

## Выбор просмотрщика

Поддерживаемые расширения перечислены в `lib/languages.ts`. Бинарные файлы, например PNG и PDF, остаются в соответствующем просмотрщике bb.

В **Settings → File openers** можно выбрать Automatic, встроенный просмотрщик bb или Monaco для каждого расширения. Контекстное меню ссылки на файл предлагает разовое **Open with…**.

## Ограничения

- Нет языкового сервера, перехода к определению, поиска использований и проверки типов проекта. Встроенная проверка TypeScript отключена: она видела бы только открытый файл и ошибочно помечала импорты как неразрешённые.
- Дерево не создаёт, не переименовывает и не удаляет файлы. Скрытые файлы и `node_modules` исключаются системой перечисления путей bb.
- Открытие файла из дерева повторно использует текущую вкладку; её название может остаться от исходного файла.
- Кнопки открытия во внешнем редакторе нет: эта возможность не предоставлена плагину.
- Открытие файлов thread-storage на удалённой машине имеет известное ограничение.

## Разработка и проверка

Плагин входит в сборку, отдельная установка не нужна.

```powershell
pnpm exec turbo run typecheck test --filter=bb-plugin-monaco-editor
```

`scripts/stage-assets.mjs` собирает ресурсы Monaco в `dist/monaco`; упаковка вызывает его через `bb-plugin-build prepare-bundled`. При работе из исходников отсутствующая или устаревшая сборка создаётся при первом открытии файла, поэтому оно может занять несколько секунд. Изменения `monaco-bundle/` также требуют обновления этой сборки.

Обычный цикл разработки обновляет `dist/app.js` и сервер плагина при сохранении. Monaco загружается отдельно при первом открытии вкладки через `files.createPreview`, чтобы его код не обрабатывался при запуске приложения для всех пользователей.

Входной файл `monaco-bundle/editor.js` включает `editor.main`, модули поиска, сворачивания и навигации, а также грамматики Monarch. Языковые службы CSS/HTML/JSON/TypeScript не включены. Не заменяйте этот вход на один `editor.api`: текст останется редактируемым, но команды поиска, навигации и сворачивания исчезнут. Сборка проверяет наличие необходимых модулей.

Для ручной проверки откройте Markdown из Explorer, переключите Preview/Source, измените текст без сохранения, проверьте предпросмотр, затем сохранение и конфликт с внешней правкой на отдельном тестовом файле.
