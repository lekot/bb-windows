# Проверка безопасности публичного выпуска

Пользователь разрешил публикацию очищенного Windows-кандидата. Старый рабочий `main`, локальные remotes и конфигурация, игнорируемые файлы и runtime-данные не входят в отправку. В GitHub `main` отправляется только `release/windows-candidate`. Атрибуция MIT исходного upstream сохранена.

## Как выполнялась проверка

Gitleaks 8.30.1 проверил все **5568 коммитов**, достижимых из коммита подготовки `b7dcb5a6d`: около **459 МБ** исторических изменений. SHA-256 загруженного сканера сверялся с контрольной суммой официального выпуска.

Сканирование выполнялось локально со стандартными правилами, пустым файлом исключений, отключёнными inline allow-комментариями и скрытием найденных значений в отчётах. Исходники и отчёты не отправлялись в сторонний сервис сканирования. Последующие изменения документации проверяются отдельно перед отправкой.

## Разбор восьми срабатываний

| Срабатывание | Результат проверки |
| --- | --- |
| Строка API-ключа в тесте квоты ZCode | Синтетическая фикстура с подставным fetch; не ключ аккаунта |
| Закрытый ключ localhost в account-pool | Уже опубликованная TLS-фикстура upstream; не личный сертификат или ключ Windows-машины |
| Три значения OAuth client ID Claude | Публичные идентификаторы клиента из upstream; не client secret и не access token |
| Issuer ID App Store Connect | Идентификатор из upstream; файл закрытого API-ключа не включён |
| Секрет локальной cloud-разработки | Фиксированное upstream-значение для localhost-помощника, не рабочий credential; Windows-launcher его не использует |
| Ключ проекта PostHog | Публичный идентификатор приёма событий upstream; Windows-launcher по умолчанию выключает телеметрию |

Проверка предков Git подтвердила наличие семи срабатываний в upstream. Восьмое относится к синтетической Windows-фикстуре. Тесты и upstream-файлы не исключались из анализа общей маской: каждое срабатывание разобрано отдельно.

## Файлы и история

Проверка текста выбранной релизной истории не нашла прежних личных расположений, известных префиксов учётных данных и новых блоков закрытых ключей.

В отслеживаемых файлах не обнаружены runtime-базы, логи, личные конфигурации авторизации, PFX/P12, закрытые SSH-ключи или реальные dotenv-credentials. Пример dotenv содержит только пустую переменную ключа. Старый частный коммит-основание форка не является предком публичной ветки.

В первоначальном кандидате единственным добавленным бинарным ресурсом был значок ZCode. Позднее по отдельному указанию пользователя добавлены пять TTF из исходного набора типографики. Это файлы шрифтов; они не содержат конфигурацию провайдеров или runtime-данные. Локальные макеты исключены.

Проверка не обнаружила личных или рабочих credentials в отправляемых данных. Поиск по шаблонам не может доказать отсутствие любого возможного секрета. Публичные upstream-фикстуры и идентификаторы остаются в истории; их нельзя использовать как рабочие credentials.

## GitHub

GitHub Actions отключены, чтобы унаследованные сценарии deploy, мобильной сборки и публикации npm не запускались автоматически. Секреты репозитория, ключи провайдеров и runtime-данные в GitHub не настраивались.
