# Аудит Windows-форка — 13 сентября 2026

**Локально проверенный кандидат; приёмка на чистой Windows ещё предстоит.** Начальные наблюдения описывают состояние до доработок. Ниже отдельно перечислены выполненные проверки и оставшиеся ограничения.

<a id="baseline"></a>
## Исходное состояние

- Рабочая ветка `main` была чистой, HEAD — `e4da5786ccf9325340c552c520920d9468cc0031`.
- Upstream: `https://github.com/get-bb/bb.git`, полученный `main` — `cf51227e1`.
- Общий предок — `267938526dfcbc0edb228ce827b5bec202c1af97`.
- Расхождение: 50 локальных и 6 upstream-коммитов; 49 локальных патчей без merge.
- Разница с общим предком: 854 файла, 107710 добавленных и 2373 удалённых строки.
- `git cherry upstream/main HEAD` не нашёл эквивалентных локальных патчей.
- `origin` рабочего репозитория указывал на временную локальную копию; `forgejo` был внутренним remote. Они не использовались как публичный адрес распространения.

<a id="concrete-findings"></a>
## Проблемы, найденные до исправлений

1. Старый launcher открывал `0.0.0.0`, задавал локальные голосовые настройки и машинозависимый endpoint.
2. Фоновый цикл не имел внешней защиты от повторного запуска и устойчивого запроса остановки; завершённый дочерний процесс сразу появлялся снова.
3. Проверка остановки в `verified-process-stop.ts` опиралась на Unix `ps` и не обеспечивала нативный Windows-сценарий.
4. `bb.cmd` распознавал упакованную раскладку только по `bb-chunks`; неполная установка могла запустить `dist/index.js` daemon вместо CLI.
5. Explorer и Screen существовали в workspace, но отсутствовали в реестре и зависимостях распространяемых плагинов.
6. Tasks и Theme Preview входили в комплект, Project Preflight включался автоматически. Скрытие кнопки не исключало сам плагин.
7. Встроенная плашка лимитов и Usage Tracker реализовывали разные варианты интерфейса; в выпуске оставлена встроенная плашка.
8. Для пяти скопированных TTF не было подтверждённых условий распространения; доступные fontsource-пакеты позволяли обеспечить запасные шрифты.
9. В прежних документах и истории были личные пути, ID проектов и локальные адреса. Чистое текущее дерево не очищает историю.
10. Отслеживаемых runtime-баз и логов не обнаружено; два PEM-файла оказались upstream-фикстурами localhost и потребовали отдельной проверки.
11. Рабочий bb обслуживал пользователя из исходного checkout, поэтому сборки проверялись в отдельной копии.

<a id="fork-structure"></a>
## Структура сопровождения

Windows-сценарии и примеры находятся в `scripts/windows/`, пользовательская инструкция — в `README.windows.md`. Платформенные операции остаются в соответствующих пакетах, политика продукта — на сервере. Состав плагинов задан явно и проверяется тестами.

Общая история сохраняется обычными коммитами и merge. Для upstream создаётся отдельная интеграционная ветка; проверяются платформенные изменения, миграции и версия протокола daemon. [Порядок обновления](../README.windows.md#update-and-integrate-upstream).

<a id="implemented-and-verified"></a>
## Реализовано и проверено

Добавлены скрытый PowerShell supervisor, именованный mutex, Windows Job Object и постоянный запрос штатной остановки. По умолчанию сервер слушает loopback, данные лежат вне Git. Подготовлены установка, проверка зависимостей, конфигурация, обновление и два сценария проверки.

Исправлены `bb.cmd`, повторный запуск CLI через Node, вызов npm на Windows и асинхронное завершение CLI после ошибок HTTP. Реальное воспроизведение HTTP-ошибки больше не завершалось аварией libuv. Harness использует заданный исполняемый файл или PATH и наследует ключ из окружения.

Включены Codex, Claude, ACP-маршруты ZCode/OpenCode/Harness, PC Control, Explorer, Screen, Git Graph, Monaco Markdown, нижняя плашка лимитов, темы и типографика. Из комплекта исключены Tasks, Taskboard, отдельный Usage Tracker, Theme Preview, Project Preflight и API Tester. Пять скопированных TTF удалены, профили используют локальные шрифты и запасные fontsource-шрифты.

<a id="release-ancestry-and-security-review"></a>
## История релиза и безопасность

Ветка `release/windows-candidate` начинается от `267938526`; очищенный снимок — `777a76492`. Старая рабочая история сохранена локально. Фильтр исключил 367 текущих путей и восстановил 144 пути upstream, не перенося прежние частные коммиты. В `433922857` перегенерирован lockfile и удалена 281 устаревшая строка.

Некоторые исходники исключённых upstream-плагинов остаются для сопровождения, но их runtime-комплект не устанавливается. Локальные Taskboard/Usage Tracker и личные диагностические материалы не перенесены в выбранную разницу кандидата.

Первичная проверка шаблонов охватила 1092 текстовых Git-объекта старой истории и 627 объектов первоначального кандидата. Она не нашла известных префиксов ключей и новых блоков закрытых ключей. Личные расположения были в старой истории, но не в проверенной выборке кандидата. Это ограниченная проверка шаблонов, не доказательство отсутствия произвольного секрета.

После разрешения пользователя очищенная ветка опубликована как `main` в [zr54211/bb-windows](https://github.com/zr54211/bb-windows). Перед отправкой выполнена [проверка всей публикуемой истории Gitleaks](windows-publication-security.md). Старый рабочий `main`, остальные локальные refs и runtime не отправлялись; force push и переписывание истории не выполнялись.

<a id="known-limitations-and-remaining-acceptance"></a>
## Известные ограничения и оставшаяся приёмка

- Установка на чистой Windows VM не проверена: изолированный checkout использовал установленные на рабочем ПК зависимости и авторизованные провайдеры.
- ZCode проверялся с уже собранным закреплённым адаптером. Нужны свежая Rust-сборка и новая авторизация. Harness используется в предварительной версии; обновления провайдеров требуют повторных проверок.
- Все пять маршрутов проверены через CLI. Доставка в открытый браузер проверена для Codex, а не отдельно для каждого провайдера и случая переподключения.
- Supervisor не является Windows-службой или задачей автозапуска. Он восстанавливает сервисы/runtime, пока работает сам.
- Браузерные проверки охватывали 1600 × 1100 и исправленный PC Control при 800 × 600; это не полный аудит адаптивности и iOS.
- Авторизация LAN, TLS, брандмауэр и упаковка Electron не входят в этот кандидат. LAN включается явно.
- Пробное слияние `cf51227e1` выявило конфликты шести файлов приложения и snapshot/journal миграции 0119. Merge отменён. При интеграции нужно согласовать выбор модели, прокрутку, запросы тредов и поле ввода, затем перегенерировать миграции. Наличие общего предка не гарантирует слияние без конфликтов.

Перед стабильным выпуском завершите проверки чистой машины и свежего адаптера, повторно проверьте состав и безопасность. Разрешение на публичный предварительный выпуск не заменяет невыполненную приёмку.
